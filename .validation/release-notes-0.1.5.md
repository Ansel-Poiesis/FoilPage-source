# FoilPage 0.1.5

协议品牌统一、BYOK 预设库与四档托管模型。

## 启动协议：foilpage://

- 主协议改为 `foilpage://`；旧 `shengjian://` 保留为兼容别名（存量 1.3.x 扩展继续可用，卸载时同删）。
- 离线拉起卡按视频 60 秒冷却，不再连点连弹；点「启动 FoilPage」后若 20 秒内桌面未上线，页面会给出手动启动指引——协议未注册时 Windows 弹"找不到应用"的静默失败从此有回音。
- 提示：安装/更新后如协议拉起无效，重启一次浏览器。

## 自带密钥（BYOK）：十家预设

- 服务商下拉内置十项预设：小米 MiMo（推荐，支持视觉）/ DeepSeek / OpenAI（视觉）/ 阿里云百炼 / 智谱 GLM / Kimi / 硅基流动 / OpenRouter（视觉）/ 火山方舟 / 自定义。
- 切换预设自动带出接口地址与默认模型（仍可手改）；切换服务商或接口地址会按安全规则清空旧 API Key 并提示重新填写，防止旧密钥被转发到新端点。

## 托管模型：四档目录

- 设置页托管模型下拉完全由服务端目录驱动（中文标签与积分倍率动态显示）；服务端加档客户端零改动。
- 当前四档：qwen-turbo 轻快整理（×0.5）、qwen-plus 忠实整理（基础积分）、deepseek-flash 润色优化（×3）、qwen-max 重型整理（×5）。分数倍率按字符折算、短文保底 1 基数。
- qwen-plus 费率复核已续期（2026-12-16）；全部档位费率见服务端复核记录。
