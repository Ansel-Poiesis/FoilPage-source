# FoilPage 品牌图标

2026-11-21，先生选用回卷耳设计：右上折角为耳朵，浅玉绿斜带为鼻梁，右下双横线兼作眼睛与文字，左上保留清晰的播放三角。

- `foilpage-master.png` 是选定附件的原始母版，1254 × 1254，像素与透明度未修改。SHA256：`89f68c5cbb676a93985b48c034f6645571192d1026d5f44b3d41173604b9d7de`。
- `foilpage-source.svg` 是内嵌母版 PNG 的自包含 SVG 封装，使用 512 × 512 视框；它不是可编辑矢量轮廓。
- `foilpage-small.svg` 保留相同造型，当前没有另行绘制的小尺寸变体。
- `node build/generate_icons.cjs` 使用工程固定的 Playwright/Chromium 等比生成桌面界面 PNG、Windows ICO 和浏览器扩展图标。
- `shengjian.*` 是现有集成的同内容别名；`shengjian-source.png`、`shengjian-paper-spiral-master.png` 是更早素材，不是当前生成源。

母版包含少量透明边缘杂点，本轮为保持先生选定的图形而原样保留。色彩为墨绿、浅玉绿与暖纸白，铜金只用于折边。本项目自有品牌资产的使用规则见仓库 `TRADEMARKS.md`。
