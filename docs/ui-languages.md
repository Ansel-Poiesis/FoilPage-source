# 界面语言

正式1.3.11已提供「设置 → 界面 → 界面语言」，支持 `简体中文` 与 `English`，保存后直接应用。2026-11-03在实际安装构建57185f4中检查了英文导航、设置与Dark主题名，并恢复简体中文；详细发行回执见 `release-closeout-20261103.md`。

设置字段为 `ui_language`，允许值 `zh-CN` / `en`；原有用户未配置时保持简体中文。它与语音识别字段 `language` 分开，切换界面不改变转写语言、模型或提示词。

英文映射覆盖应用导航、文本库、任务、导入、浏览器和通用设置控件。详细法律、来源文档和尚未收录的长消息保留原文；不将未翻译内容伪装成完整本地化。

默认主题名在英文界面中显示为 `Dark` 和 `Light · White Rock`。主题的存储键仍为 `dark` / `paper`，不改写已有主题配置。

本地化层仅处理界面字典和控件属性。用户文稿、标题、标签、输入值及可编辑内容保留原文；动态渲染继续应用当前界面语言，回切时恢复原界面标签。

验证：`npm run test:language` 检查实际设置保存、动态导航、主题名、识别配置独立、用户内容隔离及中文恢复；`pytest tests/test_ui_language.py tests/test_settings.py` 检查保存/加载、旧配置默认值与非法值拒绝。
