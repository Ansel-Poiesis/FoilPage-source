# 后端恢复与重做修复记录

2026-11-22 · TASK-5551 · 源码版本 0.1.5

对应同日《后端手册评估》的 F01–F08。本轮在现场未提交源码上继续实现，保留原有改动；交付为源码和离线证据，尚未打包、安装或部署。

## 已实现的行为

| 发现 | 实现与使用结果 |
| --- | --- |
| F01 恢复中途留下混合资料 | 导入前仍生成完整预备份。正文、SQLite、设置发布前保存本机回滚快照和持久阶段；任一步失败恢复原集合，重启先处理未完成恢复再打开资料库。快照缺失或摘要不符会停止恢复并保留现场。 |
| F02 跨目录译文路径失效 | 原文、终稿和 metadata 中的识别段落、译文、译文段落路径按当前输出根重写；保留本机数据目录与凭据。 |
| F03 托管翻译不能重做 | 每次主动翻译创建新的运行 ID，同一次执行中的模型分批及内部重试共享其操作身份。改稿后再翻译使用新 ID。 |
| F04 历史下载恢复漏扫 | 用待恢复状态及关联条件专门查询完整集合；任务、下载和媒体关联不再被最新 500 条展示假设截断。 |
| F05 未来资料库被降写版本 | 打开任何可迁移 Store 前只读核验版本；MediaStore 在写 journal/DDL 前拒绝未来组件版本，迁移与版本登记同事务。导入备份也先核验版本。 |
| F06 Agent 不能遍历 200 项以上资料 | HTTP、CLI、MCP 的任务与文稿列表提供 `cursor` / `next_cursor`，保留每页最多 200 项。游标绑定筛选与排序集合；集合变化明确返回 `cursor_stale`，需从第一页重新读。详见 [Agent 接口](agent-control.md)。 |
| F07 重关联漏检本机路径 | `candidate_path` 复用既有本机绝对路径校验，在文件访问前拒绝相对路径、网络路径及 URL。 |
| F08 后处理状态随进程丢失 | 翻译与批量整理在同一 `library.db` 的 `postprocess_runs` 保存运行、输入指纹、进度和失败。正常桌面入口注入持久 Store，重开后可查询最近失败与待重试项；不会自动重发模型请求。 |

## 恢复及产物发布

本机设置目录的 `.backup-import-recovery` 记录当前恢复阶段。`prepared` 表示重启必须回滚；`committed` 保留已导入集合；`rolled_back` 表示已回退，只需清理日志。数据库、设置和原正文快照先核对 SHA256，再执行回滚。日志或快照损坏时停止启动，保留目录与导入前 ZIP，不把不完整记录当成恢复成功。

若运行中的回滚仍因文件占用等原因失败，本实例拒绝写入，保留读取；本地 API 不重新开放，后处理连接也设为只读。解除占用后重启正常应用继续恢复。独立 Worker 发现可识别的恢复目录会在读设置、开库、写租约前拒绝执行，不替可能仍在导入的桌面进程回滚。自定义布局下 Worker 应携带正式命令生成器传入的 `--settings-dir`。

新译文以 `<原名>_译文_<语言>.<运行ID>.md` 和同名 `.segments.json` 成对生成；两份写好后才发布数据库引用。正文写入、数据库提交或源文版本检查失败，上一轮可用译文及对照均保留。源文版本检查与发布共享文稿编辑锁。启动时若 manifest 已指向本轮完整产物，则将未记完的运行收敛为完成。

批量整理也使用独立的同目录 `<文章名>.foilpage-<运行ID>.md` 文件，数据库为发布真源。停止检查、文章引用、标签、标题、源文件删除和逐项进度共用发布锁；模型调用和费用结算不持此锁。退出后返回的模型结果不能再覆盖旧文章或删除源文件。已发布的历史文章保留，文本清理识别严格的生成文件名，并保留普通 UUID 笔记；未发布的新产物在失败或取消时清理。正常 Worker 原有输出命名和 manifest 侧车行为保留。

运行记录保存必要的输入摘要、模型名称、方向和提示词版本，不复制正文或凭据。导入旧备份缺少运行表时会重建；带运行表的备份先验证记录合同，再替换当前资料。中断标记表示这次执行未确认完成，可由用户主动重新执行；不承诺从某个模型分批中间续跑。

后处理沿用现有桌面执行器，只新增同库回执表，使已完成的转写任务保持原状态。新一轮翻译开始后，上一轮迟到的结算只能更新自己的回执，不能覆盖当前运行状态。

## 验证与边界

新增故障回归覆盖：第二正文失败、SQLite/设置失败、进程中断后恢复、回滚仍失败、快照损坏、日志清理失败、跨根译文读回、未来版本拒绝、500 条之后的旧下载恢复、201/501 条完整分页、CLI/stdio 传输、路径拒绝、同方向托管重翻、改稿后重翻、失败与中断重开、发布前取消、数据库发布失败及批量退出。

固定 12 条连续样本使用真实 Bridge、Controller、SQLite、Worker 和 `run_engine`，仅替换 ASR 与翻译模型响应：12 个输入去重为 11 项，首轮 10 成功和 1 受控失败；修复后同任务身份重试，11 项完成；异步翻译、关闭重开、跨输出根恢复，再导出逐字节核对原文、终稿、识别段落、译文及译文段落。测试入口为 [test_backend_recovery_workflow.py](../tests/test_backend_recovery_workflow.py)。

最终测试结果与日志索引见项目 `巡检/后端实现-20261122/README.md`。验证没有调用真实模型、账号或支付服务，没有升级已安装应用；不代表 GUI、安装器、GPU 或线上供应商验收。
