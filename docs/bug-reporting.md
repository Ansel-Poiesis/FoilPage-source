# 报告缺陷

先在 [Issues](https://github.com/Ansel-Poiesis/FoilPage-source/issues) 搜索相同问题，再提交最小复现。包括 Windows 版本、源码提交或发行版本、运行方式、操作步骤、期望结果和实际错误。能用合成媒体复现时优先使用合成媒体。

公开报告前移除 API Key、令牌、Cookie、邮箱、设备标识、订单、签名媒体 URL、私人路径及文稿。不要直接上传完整数据库、设置、诊断包或浏览器存储，截图也需要检查。

下载问题说明来源平台和发生阶段；转写问题说明模型、设备、语言及可公开的复现样本。报告模型准确率时需有权公开的样本与真值。

可能被利用的安全问题使用 [GitHub 私密漏洞报告](https://github.com/Ansel-Poiesis/FoilPage-source/security/advisories/new)，按 [SECURITY.md](../SECURITY.md) 提供脱敏材料。
