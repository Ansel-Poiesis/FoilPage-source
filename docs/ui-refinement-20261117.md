# 0.1.5 前端布局修复

2026-11-17，TASK-5518。基于 `3bcd953` 的 0.1.5 源码适配本轮桌面前端修复。

## 修改

- 任务封面进入标题按钮内部，选择框、内容、阶段状态和删除按钮保持四列。标题按可用宽度换行，任务列表恢复纵向滚动。
- 窄窗口详情使用缩略封面、两行标题、紧凑进度和三列元信息。操作区固定在详情滚动容器底部，完整标题通过提示保留。
- 侧栏品牌区固定尺寸，导航在可用高度内滚动。作者署名与网站链接固定在导航下方，紧凑侧栏显示带可访问名称的网站图标。
- 统一主页面、准备流程、新手引导和订阅比较区的滚动条。滚动交汇处使用透明背景，滚动条颜色随主题变化。
- 缺失或读取失败的封面使用固定比例占位。文件不可用的视频持续显示标题与状态，操作菜单保留独立入口。
- 窄窗口环境检测摘要使用横向信息行，减少放大字号后的碎行。

既有绿色浮雕风格继续作为本轮设计依据。署名在紧凑侧栏缩为图标、窄窗口详情标题保留两行，是本轮前端实现取舍。
