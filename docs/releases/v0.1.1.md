# FoilPage 0.1.1

MPL-2.0 公开源码补丁版，延续 0.1.0 开始的源码版本序列。提供源码归档，当前不附加 Windows 安装器或 GPU 包。

## 依赖安全修补

| 组件 | 修补版本 | 影响位置 |
| --- | --- | --- |
| Pillow | 13.0.0 | 图像处理运行依赖 |
| Brotli | 1.2.1 | 运行锁与字体构建工具 |
| filelock | 4.2.1 | 模型等传递依赖 |
| setuptools | 84.1.0 | 传递依赖与构建支持 |
| fonttools | 4.60.2 | 字体构建工具 |
| pytest | 9.0.3 | 桌面与 Agent 测试工具 |

运行哈希锁只更新上述相关的四个运行依赖，其他运行组件保持原锁定版本。开发环境及 CI 使用 Python 3.11。旧 v0.1.0 源码归档含已识别的依赖风险，建议使用本补丁；原标签保留供追溯。

## 公开资料与署名

补齐使用指南、问题报告、项目范围与 OSPS Level 1 核对依据。软件侧栏展示 Ansel 和 keeppoiesis.com，并修复低高度窗口导航与署名重叠的问题。OpenSSF 徽章属于公开维护者自评，其范围和当前风险见 docs/security-baseline.md。

源码显示版本与浏览器扩展同步为 0.1.1，官方签名配置的兼容基线保持 1.3.13。官方账户、订阅和托管服务按独立条款提供；历史 1.x 安装版按其自己的发行与验收记录判断。
