# FoilPage 0.1.0

2026-11-13，公开源码初始版本，许可为 MPL-2.0。

本版本由现有 FoilPage 客户端工程建立独立源码快照。桌面界面、识别引擎、浏览器扩展、Agent、测试和构建脚本使用同一版本0.1.0。

包含浏览器迟到下载恢复、成功回执持久化、旧回执补查、抖音播放器布局修复、真实数据路径解析及本地扫描取消等现有改进。

公开版本使用0.1.0。签名热配置协议的能力基线保持1.3.13，以兼容现有 min_app_version 检查。签名验证、配置版本单调性和未来能力门槛继续按原协议核验。

GitHub 的 v0.1.0 提供对应提交的源码 ZIP 与 tar.gz。二进制构建、安装、真实模型结果及官方托管服务分别验证。官方托管 AI 沿用独立服务的账户和订阅体系。

版本同步、源码检查、Python、JavaScript 和界面回归由本仓库 CI 执行，实际结果以对应提交的 Actions 记录为准。
