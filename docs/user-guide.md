# 使用 FoilPage

按 [README](../README.md) 安装依赖，在独立数据目录启动。Windows 需要 WebView2 Runtime。在“准备”页检查环境、登录官方账户，再选择模型与计算设备。首次模型下载需要联网和磁盘空间；中文、人名和噪声场景需要人工校对。GPU 需要匹配的 NVIDIA 驱动与运行库。

“导入”用于主动选择本地音视频，“链接下载”用于可访问的公开视频。浏览器扩展先配对桌面端，再刷新视频页。来源平台、登录状态和网络会影响可用性；任务完成且文件存在才表示媒体已接收。

任务页查看排队、下载、识别与整理状态。失败时查看原因，确认来源或环境后重试；取消后等待当前任务停止。“视频”页管理下载或扫描到的媒体，“文本库”保留原始转写、整理正文、标签与字幕。转写是模型结果，发布前请校对。

在模型设置中配置自己的 API 服务，或选择官方托管 AI。BYOK 将所选文本发给配置的服务商；官方服务按账户套餐、积分和服务条款提供。使用前核对文稿与模型。正文编辑与 Agent 写入应基于最近读取的 revision，冲突时重新读取。

文本库提供复制、导出及字幕功能。文件位置、备份和模型缓存在设置中查看。迁移或清理前先导出备份；删除和覆盖会影响自己的资料。关闭窗口可能仅隐藏到托盘，通过托盘退出结束程序。

本地资料默认在 `%LOCALAPPDATA%\FoilPage`，开发命令使用 `.local-data`。账户验证、模型下载、公开视频下载和主动调用的模型服务需要网络。本地转写使用本机模型；本地识别不表示所有产品功能离线。日志、备份和设置可能含私人资料。

软件署名中的 [keeppoiesis.com](https://keeppoiesis.com/) 打开作者网站。普通问题见[缺陷报告](bug-reporting.md)，安全问题见[私密报告](../SECURITY.md)。
