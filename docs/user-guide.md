# 使用 FoilPage

按 [README](../README.md) 安装依赖，在独立数据目录启动。Windows 需要 WebView2 Runtime。在“准备”页检查环境、登录官方账户，再选择模型与计算设备。首次模型下载需要联网和磁盘空间；中文、人名和噪声场景需要人工校对。GPU 需要匹配的 NVIDIA 驱动与运行库。

“导入”用于主动选择本地音视频，“链接下载”用于可访问的公开视频。浏览器扩展先配对桌面端，再刷新视频页。来源平台、登录状态和网络会影响可用性；任务完成且文件存在才表示媒体已接收。

**VPN／代理与国内平台**：VPN 或系统代理会把抖音、B 站的请求绕到境外出口，平台会直接拒绝——B 站典型表现为 HTTP 412 秒拒，抖音表现为签名地址 403 或解析被校验拦截；浏览器里可能仍能正常观看，不代表下载可用。下载国内平台内容前请断开代理，或在代理工具的拆分隧道（Split Tunneling）中放行国内域名直连，至少包括：B 站 `bilibili.com`、`b23.tv`、`hdslb.com`、`acgvideo.com`、`bilivideo.com`、`bilivideo.cn`、`biliapi.net`；抖音 `douyin.com`、`douyinvod.com`、`bytecdn.cn`、`ibytedtos.com`、`pstatp.com`、`snssdk.com`、`amemv.com`。因代理被拦截而失败的任务会被自动记录，检测到代理关闭后一分钟内统一重新下载（48 小时内有效，每任务最多自动重试 3 次）；YouTube 等境外平台不受此影响，仍按代理策略访问。

任务页查看排队、下载、识别与整理状态。失败时查看原因，确认来源或环境后重试；取消后等待当前任务停止。“视频”页管理下载或扫描到的媒体，“文本库”保留原始转写、整理正文、标签与字幕。转写是模型结果，发布前请校对。

在模型设置中配置自己的 API 服务，或选择官方托管 AI。BYOK 将所选文本发给配置的服务商；官方服务按账户套餐、积分和服务条款提供。使用前核对文稿与模型。正文编辑与 Agent 写入应基于最近读取的 revision，冲突时重新读取。

托管整理按转写字数计积分：正文每 2,000 字计 1 次基数，档位倍率见设置页的「托管模型」。开启「AI 优化标题」后，每条转写另计 1 次基数；托管模式下打开它会先显示计费说明。长转写在托管模式下自动分段整理，超出单次上限时会提示并退回积分。所选托管档位不再可用时，设置会回到默认档。整理稿默认使用短段落并整句加粗重点，超过 3 句的段落会自动另起一段；整理结果未通过保真检查时改用逐字排版的原稿，并在任务清单中记录原因。开启过「转写后删除过程文件」的任务，只要字幕分段仍在，就仍可重新整理。

文本库可搜索标题、标签和文稿开头。列表卡片显示标签和日期，阅读区标题下可查看和编辑标签。阅读区可切换「原始转写」「整理稿」或对照改动，从右上角的省略号菜单可回看任务或在视频库定位。

文稿行末的「⋯」、阅读栏右上角的「更多」和文稿行右键菜单提供文稿操作，包括定位文件和导出转写字幕。只删除文本会保留视频和任务记录。也可以一并删除 FoilPage 下载且没有其他任务使用的源媒体，并选择是否保留任务记录。导入的本地原文件会保留。

此前删除遗留的过程文件，可在「设置 → 数据 → 运行数据自检」中查看。「默认勾选范围」默认选中转写残留，也可改为下载残留、两类残留或不预选。扫描后可逐项调整，点击「清理所选」执行。使用「清理残留前确认」单独控制这个操作的确认提示。文件位置、备份和模型缓存在设置中查看。关闭窗口可能仅隐藏到托盘，通过托盘退出结束程序。

本地资料默认在 `%LOCALAPPDATA%\FoilPage`，已有旧目录继续沿用，开发命令使用 `.local-data`。设置中的“文稿备份”包含任务库、设置及当前和历史输出位置的文稿、译文和字幕，不包含视频、封面与模型实体。请先停止 Worker，并等待下载、翻译和批量整理结束；缺失文件会明确报错并保留原备份。目录失联与恢复说明见[存储约定](storage-contract.md)。账户验证、模型下载、公开视频下载和主动调用的模型服务需要网络。本地转写使用本机模型；本地识别不表示所有产品功能离线。日志、备份和设置可能含私人资料。

软件署名中的 [keeppoiesis.com](https://keeppoiesis.com/) 打开作者网站。普通问题见[缺陷报告](bug-reporting.md)，安全问题见[私密报告](../SECURITY.md)。
