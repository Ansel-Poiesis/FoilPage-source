# 1.0.0 安全与验证边界

@玩家川行出品

本地转写与 BYOK 处理需要账户登录，不要求本地试用或单独软件付费；托管云端处理按当前订阅、积分、beta_access 与服务端费用保护核验。历史订单继续按原签名快照对账，代码、测试夹具和健康响应不能代替真实收款证据。

## 权益与模型调用

- 服务端验登录会话、当前设备绑定、套餐有效期和积分；客户端设置无法授予云端权限。
- 支付通知和订单查询经 RSA2 验签，再核对卖家、固定金额、订单与账本，幂等入账。历史订单保留购买时的权益快照。
- 许可证为 Ed25519 签名，客户端仅有公钥。私钥、模型供应商密钥与运营令牌留在受保护服务端配置中。
- 正文、标题独立预扣与结算。并发限制以账户为单位，在同一服务端事务处理，不能靠多设备绕过；取消、失败和重复请求不会重复扣积分。
- 供应商费用另设单次、日、月、累计限额；预留覆盖并发请求，取消已派发请求不能抹掉供应商费用。
- 运营赠送仅使用独立运营令牌与有时限的幂等请求，不向用户 MCP／CLI 开放。公告与到账通知是展示数据，不能当作权益凭据。

## 本地边界

本地程序无法保证不可修改。客户端界面不授予云端服务或账户积分。

本地处理入口只检查当前账户登录状态。

用户 Agent 可配置模型与提示词、管理内容和任务，但只通过显式操作目录调用。编辑带 revision 防止覆盖并行修改；删除、媒体重关联及开启定期清理要求对应确认。未知方法、运营接口及许可证字段不能经用户入口调用。活动记录只保存操作类别、结果和脱敏版本，不保存正文或密钥。

账户切换不删除本机视频和文本；积分、购买与通知按服务和账户隔离。迁移恢复先备份、校验摘要、事务重关联，保留回退记录。失败任务定期清理默认关闭，不删除文本或视频。

## 发行与更新

源码私有；独立公开发行仓库仅放说明、安装器、GPU 支持包和校验摘要。正式版与测试版使用分离通知渠道。更新链接限定发行仓库，拒绝附带用户信息的 URL；已安装的同版或旧版不继续显示更新按钮。

HTTPS、许可证验签和文件摘要不能代替 Windows 代码签名或用户审美验收。当前发布若未配置 Authenticode，则安装器仍可能显示系统信誉提示；不得声称已签名。
